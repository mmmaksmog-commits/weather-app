# ⛅ Небо

**Погода в любом городе мира: сейчас, по часам и на неделю. Оформление меняется под погоду и время суток.**

### ▶️ [Открыть приложение](https://YOUR_GITHUB.github.io/weather-app/)

---

## Возможности

- Поиск городов с подсказками (debounce, отмена устаревших запросов, управление стрелками)
- Определение местоположения через Geolocation API
- Текущая погода, прогноз на 24 часа и на 7 дней
- Температурные шкалы недели в стиле iOS
- Подробности: ощущаемая температура, влажность, ветер, давление, восход и закат, УФ-индекс
- Избранные города и запоминание последнего выбранного
- Переключение °C / °F
- Анимированный фон: дождь, снег, молнии, разные цвета для дня и ночи
- Обработка ошибок и работа без сети

## Стек

- **JavaScript (ES-модули)**, `fetch` + `async/await`, `AbortController`
- [Open-Meteo API](https://open-meteo.com/): бесплатный, без ключа
- CSS: glassmorphism (`backdrop-filter`), анимации, адаптивная сетка

## Структура

```
js/
├── api.js   # запросы к Open-Meteo и расшифровка кодов погоды
└── app.js   # интерфейс, поиск, избранное, анимации
```

## Запуск локально

```bash
git clone https://github.com/YOUR_GITHUB/weather-app.git
cd weather-app
python3 -m http.server 8000
```
